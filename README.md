# E-Commerce Customer Churn Prediction and Analysis

## Project Overview
This project analyzes e-commerce customer behavior and predicts customers who are likely to churn using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- SQL
- Power BI
- Jupyter Notebook

## Key Features
- Data Cleaning
- Exploratory Data Analysis
- Customer Segmentation
- Churn Prediction
- Customer Risk Level Classification
- Power BI Dashboard

## Machine Learning
Logistic Regression is used to predict customer churn probability.

## Risk Classification
- Low Risk
- Medium Risk
- High Risk

## Dashboard
An interactive Power BI dashboard is created to analyze customer churn and behavior.

## Project Outcome
The project helps identify customers who are likely to churn and supports businesses in taking early customer retention actions.
